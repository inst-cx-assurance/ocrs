# External assurance boundary (non-normative)

This chapter's former Level 1 data-model direction is superseded by ADR-0002. OCRS v0.1 has no external assurance or authorization record model.

OCRS packages preserve exact package identity, record versions, evidence provenance, manifest inventory, qualifications, exclusions, supersession, external references, and optional content integrity so a future separate protocol can reference an exact evidence package. OCRS does not define that protocol or its transaction.
