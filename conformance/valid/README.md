# Valid inputs

The canonical RFDC inputs are the ready package and controlled not-ready scenario under `examples/cw-101-reference`. This directory adds controlled valid fixtures for a coherent Review/Recommendation, a conditionally-ready Level 2 decision with a structured Condition, accepted System Handover, and effective AOCR-supported TOC. They prove core semantic representability only, not detailed ORC/AOCR/IOC/FOC or ICxA profile conformance.
